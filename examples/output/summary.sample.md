# Transformer 自注意力机制 · 一页纸摘要

> 来源：`library/<id>/transcript.srt`　|　时长：~30s 样例

## TL;DR
自注意力让序列中每个位置同时关注所有其他位置，通过 Q/K/V 点积计算权重，是 Transformer 的核心，支持全位置并行计算。

## 关键点
1. **Q / K / V 三矩阵**：每个位置生成 Query、Key、Value 三种表示
2. **点积注意力**：`softmax(Q·Kᵀ / √d) · V` 得到加权输出
3. **全位置并行**：区别于 RNN 的逐步传递，可并行 → 训练高效

## 核心术语
| 术语 | 含义 |
|---|---|
| Query | 当前位置「想找什么」 |
| Key | 各位置「能提供什么」 |
| Value | 各位置的实际内容 |
