# 质量自检清单

每次处理完一个视频、产出交付物后，逐项确认。

## 文稿层
- [ ] `transcript.srt` 非空，时间戳连续、无大段缺失
- [ ] `transcript.txt` 可读，无明显乱码 / 错字堆叠
- [ ] （Whisper 转录路径）专有名词、技术词准确度可接受；关键术语必要时提示用户人工校正

## 流程层
- [ ] 有官方字幕的视频 → 确认走了字幕路径（未触发 Whisper，秒级完成）
- [ ] 同一视频 / 文件二次处理 → 缓存命中（未重复下载 / 转录）
- [ ] 本地文件模式 → 跳过下载，直接转录
- [ ] URL 模式下载失败时 → 已给出清晰提示（链接 / 网络 / cookies），未静默失败

## 输出层
- [ ] 选定的输出文件已生成在 `library/<id>/output/`
- [ ] 调用下游 skill 前 → 已读 `mapping-table.md` 确定模板 / 主题（**尤其 ppt-animation 主题**）
- [ ] 下游 skill 产出的 HTML 可在浏览器正常打开、翻页 / 动画正常
- [ ] 学霸笔记产出 → 无 emoji（图标用 Lucide / Remix Icon）、内容页高度未超封面
