# 映射表 · 视频类型 → 呈现形式 → 具体模板/主题

> ★ 本 skill 的核心兜底机制。当用户选择「记」类输出（调用下游 skill）时，**必须先读本表**确定具体模板/主题，再激活下游 skill 传入文稿执行。
>
> **原则**：
> - 下游 skill 已明确的映射（学霸笔记 Style、flowchart 图表类型）→ **直接下放**，信任下游
> - 下游 skill 未明确的映射（尤其 **ppt-animation 的 5 套主题**）→ **由本表指定**
> - 用户显式指定 > 本表自动推断

---

## 第一层：视频类型 → 首选呈现形式

| 视频类型 | 典型特征 | 首选呈现 | 备选 |
|---|---|---|---|
| 技术原理讲解 | 讲算法 / 协议 / 机制原理 | flowchart（原理演示） | 学霸笔记 |
| 操作 / 步骤教程 | step-by-step 教学 | 学霸笔记 | PPT 复习卡 |
| A vs B 对比 | 两者比较 | flowchart（对比图） | 学霸笔记 |
| 体系 / 架构梳理 | 系统组成 / 模块关系 | flowchart（系统概览） | 学霸笔记 |
| 攻防 / 漏洞分析 | 安全 / 攻击链 | 学霸笔记 **Style B** | flowchart（攻击链） |
| 综合科普（想分享） | 做成可传播成品 | PPT 复习卡 | 学霸笔记 |

> 多个特征并存时按「首选」优先。用户说"做笔记"→ 统一走学霸笔记；说"做演示/PPT"→ 走 ppt-animation。

## 第二层：下游 skill 内 → 具体模板/主题

### A. 学霸笔记 scholar-notes（下游已明确 → 下放）

**风格选择**（由内容决定）：
- **Style A**（米黄横线纸 · 单页滚动）→ 通用技术笔记、知识点总结、科普内容
- **Style B**（皮革封面 · 翻页交互）→ 攻击链分析、漏洞笔记、深度技术研究

**布局选择**：从下游 `references/layouts.md` 的 18 种布局按内容挑选（流程→L03、对比→L04、步骤→L05、警告→L06、代码→L08、网格→L12…）。下游 `references/components.md` 有完整组件手册与图标主题表。**禁止 emoji，必须用 Lucide（Style A）/ Remix Icon（Style B）。**

### B. flowchart 概念图（下游已明确 → 下放）

**图表类型**（按下游关键词映射表）：
| 内容关键词 | 图表类型 |
|---|---|
| 步骤 / 流程 / 工作流 | 流程图 |
| 对比 / 区别 / 优劣 | 对比图 |
| 原理 / 怎么工作 / 机制 | 原理演示 |
| 架构 / 模块 / 组成 | 系统概览 |
| 交互 / 请求 / 调用 / 握手 | 时序图 |
| 历史 / 演进 / 发展 | 时间线 |
| 概念 / 关系 / 知识 | 概念图 |

### C. ★ PPT 复习卡 ppt-animation（下游未明确主题 → 本表指定）

下游给了 5 套主题但**没说何时用哪套**——按内容氛围选，调用时把主题作为参数传入：

| 内容氛围 | 主题 | 说明 |
|---|---|---|
| 技术硬核 / 工程 / 系统 | `dark-tech` | 暗色科技风（**默认兜底**） |
| 前沿 / AI / 赛博感 | `cyber-red` 或 `gradient-dark` | 红橙发光 / 深蓝紫渐变 |
| 人文 / 轻松 / 生活科普 | `clean-white` | 简约白色 |
| 复古 / 纸质 / 阅读感 | `warm-paper` | 暖色报纸风 |
| 不确定 / 通用 | `dark-tech` | 兜底默认 |

调用示例：激活 ppt-animation 时说「用 dark-tech 主题，把视频要点做成 6 页演示」。
